# EnclosureCustom

This is a custom version of the pl_enclosure_final TF2 map. I decided to make it because me and my friend found how to enable grappling hooks on any level, and so I decided to remove all the invisible walls and insta-kill blocks so that there is no limit to our curiosity.

## How to use

How to use it really depends on what you want to do

### Play the map

To play the map, download ```pl_enclosure_final_d.zip``` and extract it.
Then you go to your TF2 map folder (ex. ```C:\Program Files (x86)\Steam\steamapps\common\team fortress 2\tf\maps```) and extract ```pl_enclosure_final_d.bsp``` to the folder.
Next time you start TF2, the map should be listed as ```pl_enclosure_final_d```

### Edit the map

To edit the map is a bit more complicated than using it, first you want to download ```pl_enclosure_final_d.vmf``` to your TF2 map folder (ex. ```C:\Program Files (x86)\Steam\steamapps\common\team fortress 2\tf\maps```).
Then you want to go to your TF2 binary folder (ex. ```C:\Program Files (x86)\Steam\steamapps\common\team fortress 2\bin```) and open ```hammer.exe```.
When prompted select the Team Fortress 2 configuration, and then go to File -> Open and select the ```pl_enclosure_final_d.vmf``` file you downloaded.
If you don't know how to use the hammer editor here is a YouTube video on how to:
[https://www.youtube.com/watch?v=fdpTT2pqIVY](https://www.youtube.com/watch?v=VfK1WSo0xj0)
